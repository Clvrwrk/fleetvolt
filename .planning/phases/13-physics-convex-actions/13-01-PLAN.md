# Plan 13-01: Port Python Physics Core to Convex TS

<objective>
Port the pure-physics modules from services/simulator/app/simulation/ to TypeScript under apps/web/convex/physics/. This is the foundation: constants, types, segment builder, physics engine (force/power calc), SoC integrator (sequential loop), KPI aggregator, weather presets, speed resolver, overrides, and inputs hash.
