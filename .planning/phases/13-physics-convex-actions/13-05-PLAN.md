# Plan 13-05: CSV/JSON/PDF Exports via Convex/Vercel

<objective>
Move the export pipeline (CSV, JSON, PDF) from the Fastify API to the Convex/Vercel path. The existing Fastify export (services/api/src/exports.ts) uses Puppeteer for PDF — too heavy for serverless. Port the HTML template to a pure TS module, generate CSV/JSON client-side, and use a serverless-friendly PDF approach. Exports read simulation results from the Convex simulations table (persisted in 13-02). This completes Phase 13 success criterion #4.
</objective>

Monorepo root: /Volumes/M4 Application SSD/Projects/FleetVolt. Existing Fastify exports: services/api/src/exports.ts (POST /v1/exports/pdf — Puppeteer-based PDF), services/api/src/export-template.ts (renderExportHtml — pure HTML string builder, 174 lines). The web app (apps/web) has an export UI at apps/web/app/planner/export/page.tsx (Phase 4). The Convex simulations table (extended in 13-02 with a results field) stores the full SimulateResponse. The web client has the Convex client configured. Vercel deployment target (Phase 14 — this plan prepares for it by using serverless-compatible approaches). The export template produces: KPI summary, route map snapshot (optional), charging plan table, physics parameters, assumptions, disclaimer.
</execution_context>
