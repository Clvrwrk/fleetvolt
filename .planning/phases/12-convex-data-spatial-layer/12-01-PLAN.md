Simulation RESULTS are intentionally left in Postgres until Phase 13; only a `simulations` METADATA table lands now (RESEARCH §5). This plan does NOT ingest any data and does NOT implement spatial queries — it only lands the schema + provenance shapes and proves they push + codegen cleanly against the `sensible-oriole-832` dev deployment.
