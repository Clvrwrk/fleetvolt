### KPI Cards (D-09)

| # | Label | Source | Format |
|---|-------|--------|--------|
| 1 | Total energy | `kpis.total_kwh` | `XXX.X kWh` |
| 2 | Efficiency | `kpis.wh_per_mi` | `XXX Wh/mi` |
| 3 | Trip time | `kpis.total_time_s` | `Xh XXm` |
| 4 | Charging stops | `feasibility.stop_count` | integer |
| 5 | Total dwell | sum `charging_stops[].dwell_s` | `Xh XXm` |
| 6 | Final SoC | last segment `soc_pct` | `XX.X%` |
| 7 | Feasibility | `feasibility.verdict` + `tier` | Badge + tier tag |

### Charging Plan Table Columns (D-10)

| Column | Field |
|--------|-------|
| Location | `name` or `station_id` |
| Power | `power_kw` kW |
| Arrival SoC | `arrival_soc_pct` % |
| Energy added | `energy_added_kwh` kWh |
| Dwell | `dwell_s` → minutes |
| Departure SoC | `departure_soc_pct` % |

Row hover: `bg-[#E5E5EB]`; selected row (map sync): left border 3px `--fv-accent`.

### Map Specification (D-04–D-07)

- **Base style:** `mapbox://styles/mapbox/light-v11` (professional, matches light brand)
- **Route layer:** GeoJSON LineString(s) with SoC gradient
- **Charger layer:** Circle radius interpolate `power_kw` → 8–20px; color: `≥350` accent `#2D4A6F`, else `#8A8A93`
- **Popup on charger click:** name, power kW, arrival/departure SoC, dwell (min)
- **Hover sync:** shared Zustand `activeDistanceM`; map highlights segment by nearest `dist_m`; chart shows crosshair + tooltip
- **Missing token:** replace map area with Alert — "Map unavailable. Set NEXT_PUBLIC_MAPBOX_TOKEN to view the route." Table and chart still render.

### Chart Specification (D-08)

- X-axis: distance in miles (convert `dist_m / 1609.34`)
- Y-axis primary: SoC % (0–100)
- Y-axis secondary (toggle off by default): segment `energy_kwh`
- Reference lines: vertical dashed at each stop distance, color `#8A8A93`
- Tooltip: distance mi, SoC %, energy kWh, grade % if available
- Height: min 240px; ResponsiveContainer width 100%

### Comparison & Sensitivity (D-17–D-19)

**Comparison tray:** Horizontal chips `Scenario A | B | C` — empty slots show dashed outline "Pin a run". Max 3. Checkbox on form: "Add to comparison" (default off). Each pin stores `{ label, job_id, inputs_hash, outputs snapshot, inputs snapshot }`.

**Diff table:** Rows = KPIs + stop count + feasibility verdict; columns = A, B, C, Δ(B−A), Δ(C−A). Delta numeric cells: green if improvement (lower kWh/time), red if worse — only for energy/time metrics; feasibility shows text diff.

**Sensitivity sliders** (below form when baseline loaded):
- Payload adjustment: ±0–20% of current payload (re-run with computed lbs)
- Temperature offset: −20°C to +20°C (maps to weather preset override or API field if supported — else document as preset shift only)
- Headwind: 0–15 m/s

On slider **release** (pointerup): debounce 500ms → new POST with updated `conditions` → show delta KPIs vs baseline in tray footer.

**SCEN-03 gap map:** NOT in Phase 4 (D-20).

### Export Flows (D-21–D-24)

| Format | Trigger | Behavior |
|--------|---------|----------|
| CSV | Export menu | Client-side: segments flat table + charging_stops sheet; header comment rows with `inputs_hash`, physics/charger versions |
| JSON | Export menu | Full `SimulationJobPollResponse` blob download |
| PDF | Export menu | POST `/v1/exports/pdf` with `{ job_id, map_snapshot_base64 }`; button shows spinner "Generating report…"; disable double-submit |

PDF footer (server template): disclaimer text, model versions, `inputs_hash`, export timestamp ISO.

## Interaction States

### Scenario Form

| State | Visual |
|-------|--------|
| Idle | Fields editable; Run button enabled when Zod valid |
| Validating | Inline field errors in `#B42318` 12px below control |
| Submitting | Run button loading spinner; fields disabled |
| Polling | JobStatusBar under form: accent spinner + "Running simulation…" |
| Complete | Results canvas populated; Run button returns to "Run simulation" |
| Cached | Chip: "Cached result · hash abc123…" (first 8 of inputs_hash) |
| Failed | Alert destructive: `{error.message}` + stage; **Retry simulation** button preserves form |

### Results Canvas

| State | Visual |
|-------|--------|
| Empty (pre-run) | Centered placeholder: icon + "Configure a corridor scenario and run a simulation to see results." |
| Loading | Skeleton KPI cards + map/chart pulse on `#E5E5EB` |
| Loaded | Full dashboard |
| Partial (no map token) | KPI + chart + table visible; map slot shows token banner |

### Map

| State | Visual |
|-------|--------|
| Loading | Spinner centered in map panel |
| Ready | Route + markers visible; legend bottom-left (SoC colors) |
| Hover sync | Segment highlight 4px white casing on route; chart crosshair |
| Stop selected (table click) | FlyTo stop; popup open; table row selected |

### Export

| State | Visual |
|-------|--------|
| Idle | Export dropdown enabled when job COMPLETE |
| PDF generating | Menu item spinner; toast "Preparing PDF…" |
| PDF error | Toast destructive + retry |

### Comparison

| State | Visual |
|-------|--------|
| 0 pinned | Comparison tab shows empty state: "Run scenarios and pin up to 3 for side-by-side comparison." |
| 1 pinned | Show single column + hint to pin more |

## Accessibility

| Requirement | Implementation |
|-------------|----------------|
| Color contrast | Body text `#111827` on `#FFFFFF` ≥ 7:1; muted `#64748B` on white ≥ 4.5:1; SoC semantic colors never sole indicator — always paired with numeric % in chart tooltip and KPI |
| Keyboard | Tab order: header → form fields → Run → results tabs → table rows (Enter selects row / zooms map) → Export menu |
| Focus visible | 2px ring `--fv-accent` offset 2px on all interactive elements (shadcn default + token override) |
| Live regions | `aria-live="polite"` on JobStatusBar for PENDING→COMPLETE/FAILED transitions |
| Map fallback | Charging plan table is full data equivalent; announce "Route map" as `role="img"` with `aria-label` summarizing stop count and feasibility |
| Chart | Recharts tooltip keyboard: focusable chart container; provide data table alternative via Charging plan + exported CSV |
| Motion | Respect `prefers-reduced-motion`: disable map flyTo animation; instant chart crosshair |
| Form labels | Every Select/Slider has visible `<Label>` + `htmlFor`; weather preset options spelled out (Ideal, Hot, Cold, Headwind) |
| Error association | `aria-describedby` linking field errors to inputs |
| Skip link | Optional "Skip to results" anchor for screen reader efficiency — link targets `#results-canvas` |

Target: WCAG 2.1 AA on desktop Chrome/Firefox/Edge (PRD §6).
