01 · BRAND FOUNDATION
Engineering-grade, or it doesn't ship.
FleetVolt answers hard operational questions — energy, grades, axle loads, charger gaps — with physics, not marketing. Our design language, Technical Brand Geometry, borrows from the engineering drawing: light blueprint fields, 0.5 px construction lines, dimension callouts, monospaced annotation, registration brackets, and instrument-panel depth.

The test for every element, in every medium: would this appear on a title block or a dyno chart? If not, it doesn't belong.

CredibleCANDOR · WE SHOW THE LIMIT LINES

THE TWO-VOICE RULE
Any number a fleet manager might act on — kWh, %, lb, mi, kW — is set in JetBrains Mono. No third typeface, ever.
EMBOSSED TEXT
Light UI only: text-shadow 0 1px 1px rgba(255,255,255,0.8) on Graphite over Paper. Never on dark, never in print.
PRINT
Both faces are OFL-licensed — embed freely. Body ≥ 9.5pt, mono captions ≥ 7pt. Office fallbacks: Helvetica / Courier New.

DIAGRAMS — THE SOUL OF THE BRAND
Technical SVG only: 0.5–1 px strokes, Steel construction lines, dashed leaders, dimension ticks and datum marks, Mono annotations with units. Blueprint Blue marks the active data layer (energy, battery, route). Status colors mark node states. No decorative icons, no illustration, no clip art — if it can't be dimensioned, it isn't drawn.
07 · BUILDING NEW COMPONENTS
The seven-step recipe.
01
Start with the surface
Gradient #FBFBFD → #ECECF1 · 1px rgba(0,0,0,.06–.1) border · inset 0 1px 0 rgba(255,255,255,.9) top highlight · soft 1–2px drop.
02
Label in Mono, name in Inter
Every region gets a Mono caps label: 8.5–10px, Steel, +0.5–1.5 tracking.
03
Measure, don't decorate
If it shows a quantity, show its unit — both in Mono. No naked numbers, no filler stats.
04
Pick from the radius scale
6 / 8 / 9 / 11 / 12 / 14 / 24 px, pills 9999. Never invent a new radius.
05
Status via functional color only
Green / Amber / Red appear only when data has a status. Selection = Graphite inversion.
06
Depth is physical
Inset highlight above, inset shade below, shadow scales with elevation. No flat cards, no glassmorphism.
07
Annotate like a drawing
Callouts use 0.5px dashed leaders + Mono labels. Corner brackets go on top-level frames and modals — nothing else. Motion: hover lift only, data transitions ≤ 0.35s ease.

08 · BRAND VOICE
Numbers carry the message.
PRINCIPLE 01
Precision over persuasion
"312 kWh net, 47 kWh regen credit" — not "amazing efficiency."
PRINCIPLE 02
Engineering candor
Show limit lines plainly: "Exceeds 82,000 lb GCW. Not dispatch-legal."
PRINCIPLE 03
Dimensioned claims
Every claim carries a number and a basis: "62% vs diesel, ton-mile basis."
PRINCIPLE 04
Calm authority
No exclamation marks. No urgency theater. No rocket emoji. Ever.
✓ WE SAY
"Net energy 312 kWh — within battery envelope."
"142 mi gap on I-15. Nearest ≥350 kW site: Barstow."
"62% cost savings vs diesel, ton-mile basis."
"Simulation current."
"Select a charger node to inspect power and utilization."
✕ WE NEVER SAY
"Incredible range you can trust!"
"Uh oh! No chargers nearby 😬"
"Massive savings guaranteed."
"You're all set!!!"
"Supercharge your fleet with AI-powered magic 🚀"
VOCABULARY — USE
corridor · unit · modeled · actual · envelope · headroom · margin · constraint · dwell · regen credit
VOCABULARY — BANNED
game-changing · revolutionary · seamless · supercharge · unlock · blazing-fast · "AI-powered" as a benefit
09 · THE MASTER RULES
Every team. Every medium. No exceptions.
✓ ALWAYS
One Paper frame on a Fog canvas per screen or page
Dimension everything — units, ticks, callouts, datums
Graphite inversion for selection and primary actions
Motion ≤ 0.4s, purposeful, state-change only
Pantone + CMYK from §03 for all press work
Outlined logo files to print vendors
Mono for every actionable number
✕ NEVER
Emoji in product UI or print
Gradient backgrounds beyond sanctioned surfaces
Rounded cards with left accent borders
New hues, neons, or RGB-only colors
Fonts beyond Inter + JetBrains Mono
Decorative icons or illustration — diagrams only
Improvised dark mode — dark = Graphite panels within the light system
